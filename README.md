# Airbnb Clone Capstone

Get an Airbnb for every kind of trip → 8 million vacation rentals → 2 million Guest Favorites → 220+ countries and regions worldwide.

Administration Dashboard for an Airbnb clone application:

- Administration dashboard: create, view, update, and delete property listings.
- User authentication system manage login, logout, and user sessions.

## Technology Stack

*Frontend:* React.js, CSS
*Backend:* Node.js, Express.js, MongoDB
*Authentication:* JWT
